Domínio da aplicação

Agendamento e atendimento de consultas em uma clínica médica

Cadastros

Especialidades, médicos e pacientes, com CRM e CPF únicos.

Agenda

Consultas entre um médico e um paciente, sem conflito de horário.

Atendimento

A recepção chama o paciente, o médico atende e encerra a consulta.

Painel da sala de espera

Uma TV mostra, em tempo real pelo WebSocket, o paciente chamado, o consultório e a situação de cada sala.

RF-WS01: painel em tempo real

A recepção chama o paciente pela rota POST /api/consultas/{id}/chamar.

O servidor envia a mensagem pelo WebSocket /ws/painel para todos os clientes conectados.

O painel mostra o paciente, a sala e o médico, guarda as últimas chamadas e pode tocar um aviso sonoro.

As outras mudanças de status também são enviadas e atualizam as salas e a recepção.

{
  "tipo": "CHAMADA",
  "momento": "2026-11-10T09:31:05",

      "nome": "Dr. Bruno Lima",
      "sala": "Sala 2"
    },

Relacionamentos no código (JPA)

// Medico.java (lado dono do N:N)
@ManyToMany
@JoinTable(
    name = "medico_especialidade",
    joinColumns = @JoinColumn(name = "medico_id"),
    inverseJoinColumns =
        @JoinColumn(name = "especialidade_id"))
private Set<Especialidade> especialidades;

// 1:N: um médico, várias consultas
@OneToMany(mappedBy = "medico")
private List<Consulta> consultas;
// Especialidade.java
@ManyToMany(mappedBy = "especialidades")
private Set<Medico> medicos;
// Consulta.java (lado "muitos")
@ManyToOne(optional = false)
@JoinColumn(name = "medico_id")
private Medico medico;

@ManyToOne(optional = false)
@JoinColumn(name = "paciente_id")
private Paciente paciente;
