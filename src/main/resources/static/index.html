Clínica API – Agendamento de Consultas

Clientes WebSocket

  • Painel de chamada: tela da sala de espera (TV) que mostra o paciente chamado em tempo real.
  • Recepção: lista as consultas do dia e chama os pacientes.

Dica para a demonstração: abra o painel em uma janela e a recepção em outra, lado a lado.

Ferramentas

  • Swagger UI: documentação interativa da API REST
  • Console do H2: JDBC URL jdbc:h2:file:./data/clinica;AUTO_SERVER=TRUE, usuário sa, sem senha
